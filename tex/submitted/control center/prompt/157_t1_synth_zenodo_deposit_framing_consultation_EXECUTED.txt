Q2a. **Framing A -- Consolidated single manuscript (1 deposit)**
     A new META-PAPER absorbing PCF-2 v1.4 + Umbrella v2.2 + Picture-chain
     content into a single document, deposited as one Zenodo upload. This
     creates a fresh concept-DOI; existing PCF-2 concept-DOI (19936297)
     becomes IsSupersededBy or IsContinuedBy the new one.
     - Tradeoff: maximum coherence, but huge composition effort + orphans
       existing concept-DOI lineage.
     - Lifts D-154-1 picture-chain disposition.

Q2b. **Framing B -- Cascade-132 Option α (3 deposits; status quo)**
     Reaffirm the existing 3-step cascade.
     - Tradeoff: lowest effort (artefacts mostly exist), but picture-chain
       composition gap remains.

     Deposit PCF-2 v1.4 + Umbrella v2.2 only; fold picture-chain
     content into Umbrella v2.2 as an appendix or supplementary
     section (D-154-1 resolution path).
     - Tradeoff: removes picture-chain composition gap; reduces
       deposit count to 2; preserves PCF-2 concept-DOI lineage.

Q2d. **Framing D -- Tiered framing (anchor + supplements)**
     One ANCHOR deposit (e.g., a new M1-M12 closure narrative paper)
     + N supporting SUPPLEMENT deposits for individual program
     papers (PCF-2 v1.4, Umbrella v2.2). Cross-link via
     IsSupplementTo + IsSupplementedBy.
     - Tradeoff: high coherence + preserves individual paper identity;
       adds the anchor-paper composition cost on top of existing work.

     Fractions Program"); deposit PCF-2 v1.4 + Umbrella v2.2 +
     Picture-chain (or A/C/D variant) into the community. Community
     landing page becomes the program-level entry point.
     - Tradeoff: adds program-level discoverability + future-deposit
       continuity; requires community admin overhead.

     Per-axis Zenodo records: M4 V0, M7 V0, M8a V0, M8b V0, M9 V0
     each as independent deposits. Plus PCF-2 v1.4 + Umbrella v2.2

       artefacts (each axis already has a bridge cascade record).
